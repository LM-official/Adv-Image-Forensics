CODE SUMMARY:
1. config.py:
    This is the central configuration file.
    It contains all environment variables, absolute and relative folder paths (such as images and outputs), confidence thresholds,
    and model hyperparameters (for example, batch sizes and SVD components).
2. utils.py:
    Contains general utility functions shared across multiple files.
3. filter.py
    Filters a JSONL dataset by verifying if posts have a score and valid photos matching local files via SHA256 URL hashes.
    It then exports valid records to a CSV and creates symlinks for the corresponding images to optimize disk space.
4. trufor.py
    Runs the TruFor forensic model over the images directory in batches with a WAIT-second cool-down between batches;
    images whose .npz already exists are skipped by test.py, so an interrupted run resumes on re-launch.
    It then extracts the anomaly scores from the output .npz files and merges them into your CSV dataset using pandas.
5. performance.py:
    Evaluates TruFor's detection capabilities.
    It generates (if needed) a ground truth CSV template for manual labeling,
    then uses pandas to compute accuracy, precision, recall, and F1-score based on a threshold, saving a detailed report.
6. correlation_regression.py:
    Analyzes the relationship between TruFor anomaly scores and Crowdtangle scores.
    It uses scipy for Pearson and Spearman correlations, and statsmodels for Ordinary Least Squares (OLS) linear regression, exporting detailed text reports.
7. anomaly_regression.py:
    Runs a three-step multimodal pipeline (each step can be skipped via --skip-mask / --skip-describe / --skip-regression):
    - Step 1 (masking): reads the anomaly maps from TruFor's .npz files, binarizes them at a threshold,
      and uses OpenCV to keep only the manipulated region of each original image, saving the result as a compressed PNG.
    - Step 2 (description): loads the Hugging Face BLIP vision-language model and captions the masked images in batches,
      merging the generated textual descriptions of the altered areas into the dataset CSV.
    - Step 3 (regression): turns the descriptions into numerical features with TF-IDF (optionally compressed with truncated SVD,
      toggled by --no-svd), combines them with TruFor's visual score, and fits an OLS regression to predict the Crowdtangle score.
