CODE SUMMARY:
1. config.py:
    This is the central configuration file.
    It contains all environment variables, absolute and relative folder paths (such as images and outputs), confidence thresholds,
    and model hyperparameters (for example, batch sizes and SVD components).
2. utils.py:
    Contains general utility functions shared across multiple files.
3. filter.py
    Filters a JSONL dataset by verifying if posts have a score and valid photos matching local files via SHA256 URL hashes.
    It then exports valid records to a CSV and creates symlinks for the corresponding images to optimize disk space.
4. trufor.py
    Automates the execution of the TruFor forensic model on a directory of images using a subprocess.
    It extracts the generated anomaly scores from the output .npz files and merges them into your existing CSV dataset using pandas.
5. performance.py:
    Evaluates TruFor's detection capabilities.
    It generates (if needed) a ground truth CSV template for manual labeling,
    then uses pandas to compute accuracy, precision, recall, and F1-score based on a threshold, saving a detailed report.
6. correlation_regression.py:
    Snalyzes the relationship between TruFor anomaly scores and Crowdtangle scores.
    It uses scipy for Pearson and Spearman correlations, and statsmodels for Ordinary Least Squares (OLS) linear regression, exporting detailed text reports.
    
# TO UPDATE
7. masking.py:
    Manages the visual localization of anomalies.
    It reads the maps extracted by TruFor (.npz files), binarizes them according to a specific threshold,
    and applies this mask to the original image using OpenCV, saving an image where only the manipulated part is visible against a black background.
8. image_to_text.py:
    Implements the Hugging Face BLIP vision-language model.
    It analyzes the masked images in batches to automatically generate textual descriptions (captions) of the altered areas
    and merges these texts into the metrics CSV file.
9. multimodal_regression.py:
    Performs advanced multimodal statistical analysis.
    It uses NLP algorithms (TF-IDF and truncated SVD) to transform the textual descriptions of the anomalies into numerical variables,
    combines them with TruFor's visual score, and applies a multiple regression model to predict human judgment.
