What each block measures:
  trufor_score    - how manipulated the image looks                 (whole image)
  anomaly_txt     - CONTENT: what things or people are present      (the altered region only, describe.py)
  visual features - CRAFT: is the image well made, social-friendly? (whole image, features.py)
features.py runs before mask.py, so the visual features describe the whole image, while the text describes the manipulation itself.
The combined model therefore separates whether engagement tracks WHAT was put into the image or HOW WELL the image is made.

Scope: the visual block is the optional replication of the reference paper's visual-feature work,
and is supplementary to the main 'does the alteration drive engagement' research question.

All blocks are fitted on the same posts with the same model family (binomial GLM, logit link), so their pseudo-R2 are directly comparable.
'in-sample R2' always grows when columns are added, even useless ones:
'CV R2' (5-fold, out-of-sample) and the likelihood-ratio test are what say whether a block really adds information.
'LR vs parent' tests each block against the smaller block it is nested in.
